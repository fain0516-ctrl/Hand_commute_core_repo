인터페이스 구속 조건 명세표 (Revised Constraints Table)

전 팀 필수 준수 (Mandatory)
ID 송신 → 수신 통신 방식 / 포트 발행 주기 보드레이트 / 대역폭 데이터 구조 및 임베딩 규격 필수 구속 조건 및 안전 불변식
[IF-01] 2팀 → 3팀 단일 에셋 파일 주입 변경 시 즉시 로컬 디스크 assets/meshes/
assets/models/		 • STL은 assets/meshes/에만 단일 보관.
• XML 컴파일러 태그 meshdir="../meshes" 고정.
[IF-02] 3팀 ↔ 2팀 CAN Bus / RS-485 100 Hz (10 ms) 1,000,000 bps (1 Mbps) 10모터 패킷 (Pos, Vel, Current) • 모터 ID 1~10 고정.
• 하드웨어 퓨즈 및 과전류 차단 필수.
• 프레임 지연 < 1.5ms.
[IF-03] 3-A → 3-B UDP Port 5555 100 Hz 고정 (10 ms) 로컬 IPC (지연 < 0.1ms) JSON: q[14], dq[14], torque[10] • 14 관절 인덱스 순서(0~13) 엄수.
• 단위: 위치 rad, 속도 rad/s, 토크 Nm.
• 논블로킹 최신 1프레임 취득.
[IF-04] 3-B → 3-A UDP Port 5556 50 Hz ~ 100 Hz 로컬 IPC (지연 < 0.1ms) JSON: torques[10] • 안전 워치독: 100ms 초과 단절 시 0.0 Nm 강제 차단.
• 클램핑: 엄지 ±1.8Nm, 4지 ±2.5Nm 초과분 자동 절삭.
[IF-05A] 4팀 → 1팀 ZeroMQ / IPC / Tensor 30 Hz ~ 100 Hz 고속 토큰 스트림 촉각 특징 임베딩 ($z_{\text{tac}} \in \mathbb{R}^{D}$) • 4팀 인코더가 텍셀을 인코딩하여 1팀 VLA로 직접 주입.
• 3팀 통신 코어를 거치지 않고 상위 AI 계층으로 직결.
[IF-05B] 4팀 → 3-B UDP Socket / IPC 이벤트 발생 즉시 초경량 플래그 slip_detected[5], normal_forces[5] • 응답 지연 < 20ms 엄수 (물체 낙하 방지 긴급 인터럽트).
• 3-B 제어팀이 파지력 즉각 상향 보정.
[IF-06] 1팀 내부 Direct In-Memory (GPU) 30 Hz ~ 60 Hz GPU VRAM 버스 비전 패치 임베딩 ($z_{\text{vis}}$) & 6D 포즈 • 1팀 내부 직결 통로 (외부 통신 배제).
• ViT 인코더 패치 텐서를 GPU 상에서 VLA 어텐션 레이어로 즉시 주입.
[IF-07A] 3팀 → 1팀 UDP Port 5559 20 Hz ~ 30 Hz 약 10 KB/s 관절 프로프리오셉션 (q[14], dq[14]) • VLA의 State 토크나이저 입력으로 공급.
[IF-07B] 1팀 → 3-B UDP Port 5559 10 Hz ~ 30 Hz 약 15 KB/s JSON: target_waypoints[5], synergy • VLA 액션 출력을 3-B 제어기가 100Hz로 보간 추종.
• 변위 속도 ≤ 0.15 m/s 스무딩 필수.
