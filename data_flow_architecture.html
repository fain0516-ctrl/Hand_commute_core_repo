[IF-02] 3팀 ↔ 2팀 CAN Bus / RS-485 100 Hz (10 ms) 1,000,000 bps (1 Mbps) 10모터 패킷 (Pos, Vel, Current) • 모터 ID 1~10 고정.
• 하드웨어 퓨즈 및 과전류 차단 필수.
• 프레임 지연 < 1.5ms.
[IF-03] 3-A → 3-B UDP Port 5555
(/gripper/telemetry)		 100 Hz 고정 (10 ms) 로컬 IPC (지연 < 0.1ms) JSON: q[14], dq[14],
actuator_torque[10]		 • 14 관절 인덱스 순서(0~13) 엄수.
• 단위: 위치 rad, 속도 rad/s, 토크 Nm.
• 논블로킹 최신 1프레임 취득.
[IF-04] 3-B → 3-A UDP Port 5556
(/gripper/torque_cmd)		 50 Hz ~ 100 Hz 로컬 IPC (지연 < 0.1ms) JSON: mode: "torque",
torques[10]		 • 워치독: 100ms 초과 단절 시 토크 0.0 Nm 강제 차단.
• 클램핑: 엄지 ±1.8Nm, 4지 ±2.5Nm 초과분 자동 절삭.
[IF-05] 3-A ↔ 4팀 UDP Port 5557
(/tactile/taxel_stream)		 100 Hz ~ 200 Hz 약 250 KB/s TX: taxels (5지x16개)
RX: slip[5], forces[5]		 • 슬립 감지 알고리즘 연산 지연 < 20ms 엄수.
• 센서 노이즈 필터링(LPF 50Hz) 4팀 내부 완료 필수.
[IF-06] 1팀 → 3-A UDP Port 5558
(/perception/wrist_pose)		 30 Hz ~ 60 Hz 약 50 KB/s JSON: palm_pose, keypoints[5],
target_object		 • ROS REP-103 좌표계 준수 (X전방, Y좌측, Z상향, 단위 m).
• 신뢰도(confidence) 0.7 미만 시 플래그 0 전송.
[IF-07] 3-A ↔ 1팀 UDP Port 5559
(/vla/action_stream)		 10 Hz ~ 30 Hz 약 20 KB/s TX: 관측치 번들
RX: waypoints[5], synergy		 • 급격한 Step 지령 금지 (변위 속도 ≤ 0.15 m/s 스무딩 필수).
• 최대 허용 접촉력 상한(max_force_N) 필드 필수.
